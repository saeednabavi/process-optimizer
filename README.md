# پیش‌بینی خلوص و انتخاب نقطهٔ کار

یک فرایند مصنوعی سه ورودی دارد: دما، فشار و نرخ خوراک. مدل خلوص را پیش‌بینی می‌کند و بعد، زیر سقف هزینه، نقطه‌ای را پیشنهاد می‌کند که خلوص پیش‌بینی‌شده حداکثر شود.

```powershell
cd project\process-optimizer
python main.py
```

گزارش در `models/metrics.json` است. روی دادهٔ آزمون، MAE حدود ۰.۴۴ و R² حدود ۰.۹۸ است. نقطهٔ بدون قید خلوص ۸۵.۱ با هزینه ۱۳.۵ می‌دهد و از بودجه ۱۱ بیرون است. نقطهٔ بهینهٔ داخل بودجه خلوص ۸۴.۷ با هزینه ۱۰.۹ است. داده ساخته‌شده است تا بدون دادهٔ معدن هم قابل انتشار باشد؛ شکل مسئله همان پیش‌بینی به‌اضافهٔ تصمیم با قید است.
